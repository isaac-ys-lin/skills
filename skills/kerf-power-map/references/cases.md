# 依分類閱讀書中案例，連到本案選擇

案例要具體到人物、處境、行動與結果。使用隨 skill 提供的 Markdown 索引與完整案例頁，直接以檔案閱讀工具逐層讀取；不需要原書。

## 讀分類 → 比較候選 → 讀完整案例 → 應用

1. **找閱讀入口。** 尚未選定案例時，從 [情境總索引](case-library/index.md) 的日常問法或機制分類進入。已知人物、案例名稱或編號時，可用檔案文字搜尋直接定位該案例；搜尋是定位工具，適用與否仍由閱讀判斷。
2. **比較候選。** 分類 `index.md` 開頭的「按問題選例」把容易混淆的情況連到可比較的案例；它是閱讀起點，不是推薦排名或完整清單。依本案條件選讀，必要時擴讀下方按書排列的全部候選及相鄰分類；長表可按書分段，工具截斷時接續未讀部分。同一現象可能有不同成因，同一機制也可能導向相反結果，三書都可選，不固定每書各用一例。
3. **閱讀完整案例。** 依候選連結讀到案例內頁，核對人物、事件、類型、摘要、出處、適用提示與限制。簡介用來選候選，具名敘述以完整案例記載為準。跨類案例共用同一完整內容，沿連結讀到原頁即可。
4. **說明本案類比。** 正文要讓沒讀過書的人不點連結也能看懂故事：依 SKILL.md 第 6 節，三四行：**一兩句故事（人物、困境、做了什麼、對方反應、結果）與書名章節 → 一句關鍵差異 → 一句它讓你多注意的訊號，或讓哪個選項變好或變差**（不替本案定死先後，也不新增使用者要做的事）。連結只供回查，不能取代敘述。接到本案的判斷或圖，每項策略主要解釋一次。

分類是閱讀導航。候選不足或不貼切時，讀相鄰分類；某類沒有合適例子，只代表這次閱讀範圍內未找到。依案情找能限制目前解釋的反例，保留不同制度與權限可能使建議翻轉的條件。

## 讀懂案例頁

- **事件與結果：** 誰在什麼處境做了什麼，作者記錄什麼結果或比較。頁面沒寫的細節保留未知。
- **故事段與一句摘要：** 有「故事」段的案例可直接用來敘述；只有一句摘要的案例照摘要交代，需要完整情節時優先改選有故事段的案例。公開史實可以補充，但要標明是一般公開資料、不是案例頁內容；不補編對話、數字或結果。
- **案例類型：** 歷史事件、匿名觀察、假設示例或研究依各自類型介紹。研究的相關性、因果主張與作者解讀分開，假設示例以假設說明。
- **適用提示與限制：** 頁面的提示偏概括。閱讀後依本案的權責、利益、證據與制度補出具體相似及不可類比處；只有「情境不同」不足以支持建議。

案例頁是本 skill 自寫的摘要，不是原文引述；引用時寫書名與章節即可，不要說成書中原句或已核對原文。案例提供比較角度，當事人的行為與動機仍由本案證據判斷。沒有貼切案例時，說明缺口並完成有根據的策略。
