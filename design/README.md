# design

Blueprint 的視覺規格。第一版在 Claude Design 做出來，這裡放的是匯出的原檔，之後的程式照它實作。

- `spec.md`：頁面格線與圖表區尺寸、字級、線寬、刻度與來源列、標註規則、色彩職務、資料顯示、8 種版型與欄位、PowerPoint 輸出對應。
- `tokens.json`：同一份規格裡程式要讀的數值，包括色彩、字級、邊界、線寬與斜線填色。
- `claude-design/`：8 頁版型與 13 種圖表樣張的設計稿。要在 Claude Design 裡打開才看得到畫面；匯出時附帶的執行檔沒有放進來。

範例資料都是虛構的「河港市共享單車」。
